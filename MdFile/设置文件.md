## 在终端输入以下命令，更新信息
   git add .
   git commit -m "更新缺陷管理笔记"
   git push

## 启动若依项目的前置条件
> 启动后端： **IDEA运行后端文件ruoyi-admin\src\main\java\com\ruoyi\RuoYiApplication.java，保持运行不要关闭**
> 启动前端： **1.打开 GitBash  2.进入前端项目目录：cd /d/RuoYi-Vue2  3.启动命令：npm run dev，启动之后不要关闭GitBash窗口**
