## 启动若依项目的前置条件
> 启动数据库：**1.Win 开始菜单，搜索 `cmd` → **右键【以管理员身份运行】**  2.输入启动命令（注意你的服务名，常见是 `mysql` 或者 `mysql80`）:net start mysql  3.停止 MySQL 命令:net stop mysql**
> 启动后端： **IDEA运行后端文件ruoyi-admin\src\main\java\com\ruoyi\RuoYiApplication.java，保持运行不要关闭**
> 启动前端： **1.打开 GitBash  2.进入前端项目目录：cd /d/RuoYi-Vue2  3.启动命令：npm run dev，启动之后不要关闭GitBash窗口**
> 以上三项都启动完成之后，访问http://localhost:80，输入密码admin123登录
